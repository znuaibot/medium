## Dates (Pacific Time)

- Submission: closes **2026-12-04 14:00 PT**. No extensions, late = rejected.
- Kiro credits: request by **2026-12-01 12:00 PT** via Credit Request Form
  (48 business hours review); redeem by 2026-12-04; credits expire 2026-12-31.
- Judging: 2026-12-16 → 2027-01-29. Winners ~2027-02-03.

## Hard requirements (Stage 1 is pass/fail on baseline viability)

1. Build with **Kiro** (IDE, CLI, Web, and/or Kiro Crew). Insufficient use = DQ.
2. **New project**, created during the Submission Period. Pre-existing standard
   resources (frameworks/libraries/templates) allowed but must be disclosed.
3. Public **GitHub** repo (not GitLab/BitBucket) with a visible open-source
   license; **`/.kiro/` at repo root** showing specs/hooks/steering — NEVER
   gitignored.
4. Working application URL (+ judge credentials in the private form field).
5. Demo video: **< 3 minutes**, public YouTube, shows the project running on
   its target platform; no unauthorized third-party marks/music.
6. Text description; identify **one category** (we chose Resurrection) + bonus
   entries. All materials **English** (or with English translation).
7. Multiple submissions allowed but must be substantially different.
8. Judges may score from description + images + video alone; app must stay
   free and testable until judging ends.

## Categories

- **Resurrection**: Bring your favorite dead technology back to life.
  Reimagine obsolete tech with today's innovations or solving tomorrow's problems.
- Frankenstein: stitch a chimera of seemingly incompatible technologies.
- Skeleton Crew: a lean skeleton template + two distinct applications in two
  separate repo folders.
- Costume Contest: any app, haunting polished UI.

## Judging (Stage 2, equally weighted)

- Potential Impact (20%): credible real problem, real audience, would someone use it
- Technological Implementation (20%): depth/skill of Kiro use; thoughtful AI strategy
- Design (20%): complete coherent product experience, not a PoC
- Innovation/Idea (20%): creative, novel, unusual combinations
- Presentation (20%): video shows it working end-to-end; clear pitch; memorable

The official write-up asks about: IDE/CLI/Web/Crew differences, custom agents,
agent hooks, spec-driven development, steering docs, MCP, property-based
testing, Kiro powers. Answer with artifacts, not adjectives.

## Prizes

- Overall: $30k / $20k / $10k. Categories: $5k × 4.
- Bonus: Best Startup $10k · Best Demo $1k (top-10% + best Presentation) ·
  Best Kiro Crew App $1k (separate public repo, same GitHub account) ·
  Best Student $1.5k + Pro Max ×4 categories · Ghost of Kiroween Past $2k ·
  Blog Post: 2000 credits, top 100 scoring entries that publish a blog
  mentioning "Kiroween Hackathon 2026" during the submission period ·
  Social Blitz: 3-mo Pro+ ×5 (post must START with #KiroweenHackathon26).
- One project wins Overall XOR one Category, plus any number of bonuses.
